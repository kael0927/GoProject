## 主要内容
 - 包
## 反思
 - 包的使用：
   1.一个目录下的统计文件归属一个包，package的声明要一致
   2。package声明的包和对应的目录名习惯上写成一致
   3.包可以嵌套
   4.同包下的函数不需要导入包
   5.main包，main（）函数所在的包，其他的包不能使用
   6.导入路径 = 模块名 + 从项目根目录到该文件夹的完 整路径（用 / 分隔）
   7.所谓包，本质就是一个目录
 - 函数首字母大写代表可以被导出，表示是公共的
 - "在导入一个包的时候，如果存在init()函数，是先执行init()函数的，所以它会在main函数之前被执行，一般用来初始化包当中所需要的数据。" (知识定义)
- "同一个go文件当中，init()的调用顺序是从上到下的。" (规则总结)
- "同一个package当中多个go文件的init()函数，是把文件名字按照字符串进行排序，然后按照这个文件的顺序去执行每个文件当中的init()函数。" (规则总结)
- "对于不同的包没有互相依赖的情况，是按照main包当中import这个顺序来调用这个包当中对应的init()函数的。" (规则总结)
- "多个pkg之间存在依赖时，调用的顺序是最后被依赖的最先被执行。" (规则总结)
- "导包的时候要避免出现死循环的情况，比如说a依赖b，b依赖c，c又依赖a，那这就是一个死循环了。" (注意事项)
- "一个包可以被其他的多个包去导入，但是只能够被初始化一次。" (规则总结)

## 反思
 - interface：
    只关心方法签名，不关心字段
    func (stu *Student) getName() string 指明隶属关系 把getName函数绑定到Student这个类型上
 - var p Person = &Student{...} 
    将具体类型 *Student 的实例，赋值给 Person 接口类型的变量 p
 - Goroutine：一个虚拟线程
   Channel：ch <- 塞数据，<-ch 取数据。当管道没有数据时，<-ch 会阻塞等待
